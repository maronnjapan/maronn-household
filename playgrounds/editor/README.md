# Editor Playground

`@maronn/editor` パッケージの開発用プレイグラウンドです。

## 注意事項

- このプレイグラウンドは**開発専用**です
- 本番環境へのデプロイは予定していません
- エディタの動作確認と開発に使用します

## 起動方法

```bash
# ルートディレクトリから依存関係をインストール
pnpm install

# プレイグラウンドを起動
cd playgrounds/editor
pnpm dev
```

ブラウザで http://localhost:3001 を開いてください。

## 機能

- Milkdown エディタのリアルタイムプレビュー
- Markdown 形式の出力確認
- エディタのプロパティテスト
