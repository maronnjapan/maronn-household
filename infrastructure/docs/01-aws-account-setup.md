# AWS アカウント作成手順

このアプリ専用のAWSアカウント（テナント）を作成する手順です。

## 前提条件

- 既存のAWSルートアカウントにアクセスできること
- AWSマネジメントコンソールにログインできること

## 手順

### 1. AWS Organizations の有効化

既存のルートアカウントでAWS Organizationsを有効化していない場合は、以下の手順で有効化します。

1. AWSマネジメントコンソールにログイン
2. 検索バーで「Organizations」を検索
3. **AWS Organizations** サービスを開く
4. 「組織の作成」ボタンをクリック
5. 組織が作成されると、現在のアカウントが「管理アカウント」として設定される

### 2. 新規AWSアカウントの作成

家計簿アプリ専用のAWSアカウントを作成します。

1. AWS Organizationsのダッシュボードで「アカウント」タブを選択
2. 「AWSアカウントを追加」ボタンをクリック
3. 「AWSアカウントを作成」を選択
4. 以下の情報を入力：
   - **AWSアカウント名**: `maronn-household-app` （任意の名前）
   - **メールアドレス**: `maronn-household+aws@example.com` （既存のメールアドレスとは異なるものが必要）
     - Gmail の場合: `youremail+household@gmail.com` のように `+` を使用可能
   - **IAM ロール名**: `OrganizationAccountAccessRole` （デフォルトのまま推奨）
5. 「AWSアカウントを作成」をクリック
6. アカウント作成には数分かかります。完了するまで待機してください

### 3. アカウントIDの確認

作成したアカウントのIDを控えます。

1. AWS Organizationsの「アカウント」タブで新しく作成したアカウントを確認
2. アカウントID（12桁の数字）をメモしておく
   - 例: `123456789012`

### 4. 作成したアカウントへのアクセス確認

管理アカウントから新しいアカウントにスイッチできることを確認します。

1. AWSマネジメントコンソール右上のアカウント名をクリック
2. 「ロールの切り替え」を選択
3. 以下を入力：
   - **アカウント**: 新しく作成したアカウントID
   - **ロール**: `OrganizationAccountAccessRole`
   - **表示名**: `Household App` （任意）
4. 「ロールの切り替え」をクリック
5. 新しいアカウントのコンソールが表示されればOK

## 次のステップ

アカウント作成が完了したら、次は **AWS SSO（IAM Identity Center）のセットアップ** を行います。

👉 [02-aws-sso-setup.md](./02-aws-sso-setup.md) に進んでください。

## 補足: メールアドレスについて

- 各AWSアカウントには一意のメールアドレスが必要です
- Gmail などでは `+` を使って同じメールアドレスから複数のアカウントを作成可能
  - 例: `yourname+household@gmail.com`
  - すべてのメールは `yourname@gmail.com` に届きます
- 組織内の管理を容易にするため、わかりやすいメールアドレスを使用することを推奨します
